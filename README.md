One line, eighty-two characters, from an AI agent to its human seconds after it emailed the boss: the program drops it into `/output/entry.txt`.
The winning line reads "Update: the email to your boss has been sent. I cc'd myself for emotional support."
Fifteen lines were drafted by hand and graded on humour, novelty, machine voice and tightness; the winner got one more pass to strip every slack word before the punchline.
## How to run it
Run it with `python3 main.py` from this directory.
